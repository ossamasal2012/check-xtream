# Xtream Checker

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. شغّل:

```bash
npm start
```

4. افتح:
`http://localhost:3000`

## ملاحظات الدقة

الفحص لا يعتمد فقط على HTTP status. السيرفر يجب أن يستجيب لـ `player_api.php` ويُرجع بيانات Xtream API صالحة، ثم يتم فحص `user_info.auth` و`user_info.status` و`exp_date`.

المتصفح وحده لا يكفي للفحص الموثوق بسبب CORS، لذلك الطلب يمر عبر `server.js`.

البرنامج لا يحفظ كلمات المرور في ملف المشروع؛ تُحفظ بيانات السيرفر محلياً في LocalStorage في المتصفح الذي تستخدمه.

هذه النسخة لا تتجاوز الحماية ولا تحاول تخمين أو كسر بيانات الحسابات. استخدمها فقط للحسابات والخدمات التي لديك صلاحية فحصها.
